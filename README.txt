BIRTHDAY WEBSITE — PALLAVI
=========================
Files:
- index.html
- style.css
- script.js
- assets/

DEPLOY:
Upload the complete folder to any static hosting service. No server or database is required.
You can also open index.html directly in a browser.

CONTROLS:
- Click the bottom arrows/dots
- Mouse wheel
- Keyboard arrows / PageUp / PageDown / Space
- Swipe on mobile
- On the greeting-card page, click/tap the envelope to open it.

CUSTOMIZE:
All five pages are contained in index.html. Colors, typography, animations and layout are in style.css.
The website currently uses Google Fonts from the internet. If you need fully offline hosting, download the fonts and self-host them.
